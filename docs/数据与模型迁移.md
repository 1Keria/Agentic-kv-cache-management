## 存储原则

GitHub 保存代码、脚本、配置、测试、设计文档、精简报告和小型 manifest。Hugging Face 保存模型检查点、缓存数据、展开后的 workload、完整实验结果、事件流和服务监控日志。

以下内容不迁移：虚拟环境、pip/Hugging Face 缓存、`__pycache__`、Notebook checkpoint、PID 文件，以及可从公开来源恢复的第三方原始副本。`experiments/evicition_policy/data/raw/skillsbench/` 因此保留在本地，不上传到项目 HF 数据集。

## 按需恢复

先登录 Hugging Face：

```bash
hf auth login
```

恢复淘汰策略实验的派生数据和完整结果：

```bash
hf download 1Keria/agentkv-runtime \
  --repo-type dataset \
  --revision b4f3af2b3e26b1cb4b4d3dc0e4ae7f9576dea5d4 \
  --include 'experiments/evicition_policy/data/**' \
            'experiments/evicition_policy/results/**' \
  --local-dir .
```

恢复请求分类模型：

```bash
hf download 1Keria/agentkv-runtime \
  --repo-type dataset \
  --revision b4f3af2b3e26b1cb4b4d3dc0e4ae7f9576dea5d4 \
  --include 'models/request_classifier/cache/**' \
            'models/request_classifier/checkpoints/**' \
  --local-dir .
```

恢复固定分区实验数据和结果时，将 `--include` 改为：

```text
experiments/固定分区试验对比/data/**
experiments/固定分区试验对比/results/**
```

已有 `workloads/` 和 `models/MLP/` 也位于同一私有数据集。本次迁移前已逐文件核对远端大小一致，没有重复上传。
