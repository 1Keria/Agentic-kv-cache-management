## 3. 已实现和验证的内容

入口：`scripts/prepare_data.py`，依赖现有 Python 的 `requests`，不安装或覆盖已有环境。

### inventory

筛选三个指定配置，记录历史清单哈希、大小、实际文件存在性和元数据存在性。输出 `data/historical_source_manifest.json`。此文件明确标记 revision 未锁定，不冒充当前公开数据版本。

### download

- 首次读取发布源的文件元数据，将不可变 commit 写入 `data/source_lock.json`；之后复用同一 lock。
- 支持官方地址与 `https://hf-mirror.com` 两个入口；镜像下载仍固定同一 commit，并保留入口信息。本次元数据和文件均经镜像获取，不宣称另行从直连官方地址完成了独立交叉校验。
- 大仓库顶层文件列表可能截断，本次实测返回 100,000 条且遗漏选定配置；已改为按三个配置目录递归分页枚举，不把截断列表误报为数据不存在。
- 只下载选定的原始轨迹及相关配置/结果元数据、数据卡，不下载其他模型的全部包。
- 同时验证文件大小和上游 LFS SHA-256 / Git blob SHA-1，不以大小相同代替完整性验证。
- 支持有限并发、重试和再次运行时跳过已通过校验的文件；中断文件重新下载，不宣称字节级续传。
- 如 `--source-root` 下已有同路径文件，只有通过固定上游哈希验证后才复制；不会仅凭旧 manifest 的大小认定备份可信。
- 只写本实验目录，不在日志中打印凭据、完整响应正文或命令行代理密码。

### audit

- 对恢复文件重新校验，解析原始 JSONL，保留请求体、响应体、原始行号和所有原始时间信息。
- 时间缺失不补 0，输出长度缺失不补 1，负间隔不截成 0，长等待不截成 30 秒。
- 不把 `duration_ms` 自动当作响应完成证据；时间戳差值只标为候选，真实语义仍需审计采集实现。
- 非文本输入、损坏行、重叠请求、时钟不明确、来源模型不匹配等均显式标记。
- 不因任务奖励为 0、任务失败而排除；部分轨迹和观察结束状态保留原值/未知。
- 完全相同的规范化记录序列去重；相同请求但不同输出或等待不自动删除，以免丢失有效尝试。
- 同任务归为同一划分单元；相同请求序列的跨任务别名进一步合并，避免这类重复跨集。
- 输出任务级约 20% 校准 / 80% 评估的**候选划分**，种子 42；不会将其直接标记成最终服务 workload。

验证：`tests/test_prepare_data.py` 的 **17 项合成单元测试通过**，包括缺失值、长/负间隔、坏行、非文本保留、来源校验、哈希、路径安全、划分、防止假报 ready，以及顶层列表截断时正确处理目录分页和镜像下一页地址。测试只验证脚本逻辑，不替代实际数据审计。日志保存于 `results/audit/unit_tests.log`。

## 5. 重现下载与审计入口

从项目根目录运行：

```bash
export PYTHONPYCACHEPREFIX="$PWD/experiments/evicition_policy/runtime/pycache"
python experiments/evicition_policy/scripts/prepare_data.py inventory
python experiments/evicition_policy/scripts/prepare_data.py download --endpoint https://hf-mirror.com --workers 6
python experiments/evicition_policy/scripts/prepare_data.py audit
python -m unittest discover -s experiments/evicition_policy/tests -v
```

如有可用代理，仅对本次命令指定 `--proxy http://127.0.0.1:<实际端口>`；不要把账号密码写进命令行。备份符合发布源目录结构时，可给下载命令添加 `--source-root <备份根目录>`。若仍无法访问发布源锁定哈希，需要先单独核验备份来源，不能跳过校验。

退出码：0 表示该步骤执行成功，不代表可上 GPU；下载失败返回 1；审计缺原始数据返回 2。应检查审计 JSON 的状态和剩余门槛。
