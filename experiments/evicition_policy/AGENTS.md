# 本实验目录约束

- 使用简体中文沟通；实施前阅读本目录 `README.md`，以其中当前阶段和验收标准为准。
- 本实验只研究纯 Agent 请求的原生 KV Cache 淘汰策略，不训练或接入身份/复用预测小模型，不启用业务分区，不使用自研淘汰策略。
- 新增脚本、配置、测试、数据、运行环境、缓存、日志和报告统一放在本目录。已有外部大模型权重和原始数据可只读引用，记录来源和哈希。
- 不覆盖或重置项目现有 `Engine/sglang`、已有虚拟环境及其他实验结果。官方引擎使用本目录下的隔离环境、固定版本，核对实际导入路径。
- 不将规划中的脚本名、策略兼容性、数据数量或容量写成已验证事实。更新文档时明确“计划、预跑、正式结果”。
- 原始时间缺失、生成与历史不一致、Full/SWA 事件不完整时，显式标记限制，不编造观测数据或精确归因。
- 服务对照保持模型、后端、实际容量和回放规则一致。不同策略之间重启服务，保存中断结果，只清理本实验拥有的进程。
- 本阶段不修改引擎决策或加入观测补丁；需要扩大实验边界时先说明具体决策。
- 不提交原始敏感请求、密钥、凭据、环境目录和大日志；不主动执行 git commit/push。
